# Support

Use
[GitHub Discussions](https://github.com/Jason-Doyle/ContentContractEngine/discussions)
for setup questions and usage help.

Use [GitHub Issues](https://github.com/Jason-Doyle/ContentContractEngine/issues)
for reproducible bugs and focused feature proposals. Security vulnerabilities
must use the private reporting path in [SECURITY.md](SECURITY.md).

Before requesting help:

1. Use Node.js 22 or newer.
2. Run `npx content-contract --version`.
3. Include the command, exit code, and redacted diagnostic output.
4. Reduce the report to the smallest safe configuration and content sample.

Contributors working from a clone should run `npm ci` and `npm run qa` before
opening a pull request.

Never include secrets, private documents, access tokens, or confidential content
in a support report.
